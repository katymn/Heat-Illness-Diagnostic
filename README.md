# Heat Illness Diagnostic Tool

## 🚨 Project Overview

Heat illnesses are common in hot, humid climates and can range from mild discomfort to life-threatening emergencies. Prompt recognition and treatment are essential to prevent severe health consequences. This interactive web-based tool is designed for **educational purposes only** and helps users identify symptoms associated with different types of heat illness through a simple questionnaire.

Users answer yes/no questions about symptoms, and the tool suggests a potential heat illness along with care advice and educational videos.

---

## 💻 Tech Stack

- **Languages**: HTML, CSS, JavaScript
- **Libraries/Technologies**: DOM manipulation, iframe embedding for video content
- **Tools**: Any modern web browser

---

## 🛠 Features

- Interactive symptom-based questionnaire to suggest heat illness types
- Educational videos embedded for better understanding of conditions
- Responsive design for accessibility across devices
- Clear guidance on symptoms and first-aid care advice
- Restart functionality to retake the diagnostic quiz

---

## 📂 File Structure

- `index.html` — Main HTML page with layout and elements
- `heatStyles.css` — Styling for layout, colors, fonts, responsiveness
- `heatJavascript.js` — Interactive logic for symptom questions, answers, and diagnosis

---

## 🚀 Installation & Usage

1. Clone the repo or download files:
   ```bash
   git clone https://github.com/yourusername/heat-illness-diagnostic.git
2. Open `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari).
3. Click **BEGIN** to start the symptom diagnosis.
4. Answer yes/no questions to see potential heat illness and care info.
5. Use **RESTART** to take the quiz again.
6. No additional setup or dependencies required!
